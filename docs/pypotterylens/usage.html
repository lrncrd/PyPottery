Using PyPotteryLens

This guide follows the workflow tab by tab, in the order you will use them. Each step builds on the previous one, and everything is saved automatically inside your project.

The workflow at a glance

Project Manager → 1. PDF Document Processing → 2. Apply Model → 3. Review Annotations & Masks → 4. Tabular Information → 5. Post Processing → Export ZIP

Project Manager

Every dataset lives in its own project: a self-contained folder with your PDF, images, masks, tables and exports. Create one project per monograph, site or assemblage.

Create a project

  1. In New Project Dossier, type a Project Name (required), for example Scavi_Capena_2024.
  2. Optionally add a Description (site context, trench, assemblage notes) and pick a Project Icon Stamp.
  3. Click Create Project.

Open, refresh and delete

Existing projects are listed in the Project Repository. Click a project card to activate it: from that moment every tab works on that project. Use Refresh if you added a project from outside the app.

Warning

Deleting a project removes everything inside it: the source PDF, extracted images, masks and annotations, and exported data. The app asks for confirmation, and it cannot be undone.

1. PDF Document Processing

Upload the PDF of the monograph or report. PyPotteryLens extracts every page as a high-resolution image.

  1. Select the project first (the PDF is attached to the active project).
  2. Decide whether the PDF is made of single pages or scanned spreads (two facing pages on one sheet, as when a book is laid open on a scanner).
  3. If it is a spread, switch Split Scanned Spreads ON before choosing the file. Each sheet is cut at the spine into two separate plates. For a normal digital PDF leave it OFF.
  4. Click Select PDF File (or drag the file onto the box) and wait for the processing to finish.

Important

A project can hold only one PDF. To use a different document, click Remove PDF in the Ingestion Status box (this deletes the PDF and its extracted page images, and you will need to upload a new one) or create a new project.

Tip

Use simple file names without spaces or special characters (Cardarelli_2022.pdf, not My Document (2024) v2.pdf). Extracted pages are saved as {project}_page_0.jpg, {project}_page_1.jpg, … and, with splitting, ..._page_0a.jpg, ..._page_0b.jpg.

2. Apply Model

The detection model looks at every plate and outlines each pottery drawing with a mask.

Choose the model and the confidence

  • Active Vision Model: the YOLO model trained on archaeological profiles. The default is fine for most publications.
  • Confidence Threshold (0.10-1.00, default 0.50):
    • Higher values give fewer detections with higher precision, but may miss difficult drawings.
    • Lower values catch subtle drawings, but may add false positives.
    • Start at 0.50 and adjust on a sample.

Full dataset or a quick test

Under Execution Mode choose:

  • Full Dataset: process all the images selected in the project.
  • Diagnostic Test: process only the first 25 images, to try parameters quickly before committing to a long run.

Choose which images to process

The Project Figures gallery shows all the extracted pages. Use Select All or Deselect All and click single pages to include or exclude them (title pages, indexes, blank sheets). The badge shows how many images are queued.

Click Apply Model to Project. A full-screen overlay shows the progress and the current file, and Stop Processing cancels the run.

Tip

Run a Diagnostic Test first, look at the result in the next tab, and only then run the full dataset with the confidence you settled on.

3. Review Annotations & Masks

The model is good, not perfect. Here you check every plate, correct the masks, and finally cut out the individual drawings (“cards”).

Open a plate by clicking it in the Images List (the sidebar can be collapsed with Images List). Use Prev / Next to move between plates and the + / − / Fit controls, or the mouse wheel, to zoom and pan.

Tools

Tool What it does Key
Brush Paint with a round cursor; on release the stroke becomes a clean vector polygon B
Polygon Click to place vertices; click the first point (or double-click, or Enter) to close; Backspace removes the last vertex, Esc cancels P
Eraser Sweep over vertices to erase them E
Colorize Show each vessel mask in a different color
Clear Remove all polygons on the current image

The Size slider sets the diameter of the brush and eraser (5-100 px). The Expansion slider (0-100 px, default 8 px) adds padding around every vessel, so cards are cut with a little margin.

Vessels drawn inside other vessels

Some drawings show a small vessel inside a larger one. Use Polygon to outline the inner vessel: each polygon becomes a separate card when you extract, and the inner area is automatically whitened out of the containing card. The Vessels & Polygons panel lists every polygon; click one to select it, and use Delete to remove it.

Spot fused masks with Colorize

Turn on Colorize: every vessel mask gets its own color. If two vessels share one color, their masks are fused: separate them with the eraser. Colors update live after every stroke.

Calibrate the scale (optional)

If you want real-world sizes, tell PyPotteryLens what the printed scale bar measures:

  1. Select the Scale tool.
  2. Click the two ends of the graphic scale bar on the plate.
  3. Type the length in cm and confirm (Enter); Esc cancels.

The ratio is saved in Scale calibrations and used to fill the px_per_cm value when you extract the cards. For pages with more than one scale, use the Zone button on a scale and draw a rectangle to limit it to that part of the page.

Once you have measured scales on several plates, Calibrate Scales opens a histogram of all the ratios in the project. Click an empty spot to add a center line, drag lines to move them, double-click to remove them, then Apply Calibration to snap outlier measurements to consistent values.

Extract the cards

When the masks on all plates look right, click Extract Cards. A dialog asks you to confirm:

  • Overwrite warning: cards already extracted in this project will be regenerated.
  • Clean Artifacts & Numbers (optional): removes isolated inventory numbers, section cuts and stray fragments outside the vessel.

A progress overlay (Extracting Cards from Masks) shows the run, and Stop Processing cancels it. The cards are saved in the project and are what the next tabs work on.

4. Tabular Information

Attach archaeological data to each extracted vessel.

The table

The center shows the plate with a bounding box and an ID on each vessel (toggle them with Show boxes; click a vessel to inspect it). On the right is the table with one row per vessel. Move between plates with Prev / Next or from the Project Plates list.

  • Add Column: type a name and click Add Column. Columns are persistent across the whole project.
  • Edit: click a cell and type. Every edit is saved immediately.
  • Fill Column: choose a column, type a value and click Fill Column to set it for every row of the current plate.
  • Clear Page Data: empties the values on the current plate and keeps the columns.
  • Mark as Reviewed: flag a plate as done, to keep track of your progress.
Note

Avoid commas inside cell values (CSV limitation).

AI-assisted extraction (optional)

Plates often print a table number, figure number and caption next to each drawing. The AI can read them for you.

  1. Click Backend and pick the engine:
    • Local (Gemma 4 E2B): runs on your machine, after a one-time model download (~10 GB). It is only offered if your hardware qualifies (see Hardware Requirements); otherwise the interface explains why.
    • OpenRouter API: enter your API key and a vision-capable model name.
  2. Optionally open Prompt to add context, such as how plate numbers are printed in this publication.
  3. Click Extract References for the current plate, or Batch Extract for the project (you can limit it to a page range with the from/to fields). A progress overlay shows the tokens used, and Stop Processing cancels it.

Canonical column names. Put a column name in [square brackets] inside the prompt and that exact name becomes the column: “Extract also [Scale] indicated next to the rim” or “Transcribe the [Ceramic Class]”. This keeps column names identical across all pages.

Use Crops. Turn it on to read small inventory numbers from cropped, enlarged versions of each drawing. This improves accuracy for tiny labels.

Tip

Always check AI output. Try the extraction on one plate, adjust the prompt, and only then run the batch.

5. Post Processing

The last step standardizes the extracted cards: orientation and completeness.

  1. Choose the automatic corrections:
    • Auto V-flip turns upside-down vessels the right way up (rim at the top).
    • Auto H-flip standardizes the side of the profile.
  2. Click Process All Images. A classifier also labels each card ENT (a substantially complete profile, blue border) or FRAG (a fragment, orange border).
  3. Review the grid. All cards are shown at their real relative size (the largest one fills the maximum thumbnail). Hover over a card to reveal its controls:
    • Flip vertical / Flip horizontal: override the automatic orientation.
    • ENT / FRAG pill: change the classification.
    • Exclude: leave the card out of the export (it is greyed out); click again to include it.
    • Click the image to open a full-screen lightbox.

Export

Click Export Results, enter an Export Acronym (letters, numbers and underscores only, for example OSA_2024) and choose Export ZIP.

The ZIP contains:

  • the cards renamed with your acronym (OSA_2024_1.png, OSA_2024_2.png, …), leaving out the excluded ones;
  • OSA_2024_metadata.csv, which merges your tabular data with the ENT/FRAG classification, with every field written as plain text. If you calibrated scales, it also carries the px_per_cm column.

Where your files are

projects/
└── YourProject_20250104_123456/
    ├── project.json              # Project metadata
    ├── pdf_source/               # Original PDF
    ├── images/                   # Extracted page images
    ├── masks/                    # Detection masks
    ├── cards/                    # Individual vessels
    │   ├── mask_info.csv         # Your tabular data
    │   └── mask_info_annots.csv  # Bounding boxes
    ├── cards_modified/           # Oriented and classified cards
    │   └── classifications.csv   # ENT / FRAG results
    └── exports/                  # Exported data

Projects are timestamped automatically, so names never collide, and you can work on several at once.

Tips

  • Do a Diagnostic Test before every big run.
  • Review the masks before extracting cards: it is much cheaper than fixing cards afterwards.
  • Keep project names descriptive (Capena_2018_Vol_II).
  • Very large PDFs (500+ pages) take a long time: consider splitting them into sections.
  • Something not working? See Troubleshooting.
