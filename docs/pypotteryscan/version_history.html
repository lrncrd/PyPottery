Version History

Development timeline and changes

Latest Release

Version 0.1.2 (September 2026)

OCR and models

  • GLM-OCR: a lightweight local OCR model (0.9B parameters) that runs on CPU or GPU, so an NVIDIA GPU is no longer required. It is the recommended choice on first launch; OlmOCR-FP4 remains available for NVIDIA GPUs, and you can still start without any OCR model
  • New setup screen with a progress bar per model and recovery actions when a download fails: Retry Download, Choose a Different Model, Continue Without OCR
  • The few-shot parsing model is now Qwen3.5-2B (it was Qwen3-1.7B). If its download fails the app still starts, and only the Parser Studio is unavailable
  • Process OCR tab redesigned: live status while the boxes are read, the recognized labels listed as they arrive, a log drawer, Copy Extracted Texts and Re-run OCR Processing

Annotate and Load

  • Every change is saved automatically, with a Saved badge; a mode badge shows which tool is active
  • Move a selected box with the arrow keys (2 px, or 10 px with Shift), and delete it with the Delete Box button or Delete
  • Drag and drop of files and folders in the Load tab, a Plate Catalog of thumbnails, and Add Files / Add Folder to extend a project at any time
  • In-app confirmation dialogs replace the browser pop-ups

Clean Drawings

  • Straighten tool: precision slider (−45° to +45°), micro-adjustment buttons, quarter-turn rotations, an alignment grid and Auto-Fit to trim the blank margins
  • Eraser presets (6, 16, 32 and 64 px), a brush preview circle, mouse-wheel size and zoom, and new shortcuts (G, R, [, ], +, -)

Export

  • One-click ZIP package with the JPEG drawings, the catalogue as Excel and CSV, the box coordinates for machine learning (Excel and CSV) and a short README, plus a separate Download Excel button
  • The archive prefix is sanitized to letters, digits, _ and -
  • Export files are downloaded by the browser instead of being saved to a chosen folder

Parser Studio

  • The x at the end of a row of Current Parsed Data removes a field you assigned by mistake, together with its highlight
  • Added Examples is collapsed at the start; its title opens and closes the list, and the count stays visible
  • Previous, Next and Reset ask for confirmation when you assigned fields on the line and did not add it as an example yet
  • The pill that shows the step being processed and the box with the recognized text labels are now spaced apart in the Process OCR tab

Interface and stability

  • New look shared with the other PyPottery applications, with locally served fonts
  • The app now shuts down by itself a few seconds after you close its browser tab
  • Crashes are reported with a timestamp and the name of the thread that failed, which makes problems easier to diagnose
